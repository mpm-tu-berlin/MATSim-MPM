# Data Directory

This directory contains input data and generated intermediate/output files for the network generation pipeline.
The large files are **not tracked by git** – see below for what is needed and how to obtain it.

## Required Input Files (download manually)

### DTM Elevation Rasters (by Sonny)

| File | Used by | Source |
|------|---------|--------|
| `DTM Germany 20m v3b by Sonny.tif` | Script 03, 04 | [Sonny's LiDAR Digital Terrain Models](https://sonny.4lima.de/) |
| `DTM Germany 50m v3b by Sonny.tif` | Script 02 | [Sonny's LiDAR Digital Terrain Models](https://sonny.4lima.de/) |
| `DTM Cyprus 50m v1 by Sonny.tif`   | (optional)  | [Sonny's LiDAR Digital Terrain Models](https://sonny.4lima.de/) |

Download the files from **https://sonny.4lima.de/** and place them in this `data/` directory.

## Generated Files (created by the pipeline)

Run the scripts in order to regenerate all intermediate and output files:

| File | Generated by | Description |
|------|-------------|-------------|
| `germany_simplified_DF.gpkg` | Script 01 | Simplified OSM road graph (motorway/trunk/primary) |
| `germany_detailed_sorted_DF.gpkg` | Script 01 | Detailed OSM segments sorted to match simplified edges |
| `germany_3d_raster_clamped_DF.gpkg` | Script 02 | 3D road geometry with elevation from DTM |
| `germany_3d_raster_clamped_DF_kdtree_from_roads3d_epsg4326.npz` | Script 03 | KDTree for fast elevation lookup |
| `kdtree_germany_dtm20m_1m_acc.npz` | Script 03 | KDTree from 20m DTM (higher accuracy) |
| `Germany_max_*_long_V0.xml.gz` | Script 04 | MATSim network XML (before smoothing) |
| `Germany_max_*_smoothened_*.xml.gz` | Script 05 | Final smoothed MATSim network |

## Pipeline Order

```
01_save_filtered_osm_locally.py
    → germany_simplified_DF.gpkg
    → germany_detailed_sorted_DF.gpkg

02_generate_3d_roads_from_osm.py.py   (needs DTM 50m TIF)
    → germany_3d_raster_clamped_DF.gpkg

03_build_kdtree_from_filtered_points.py
    → *_kdtree_from_roads3d_epsg4326.npz

04_build_matsim_network_from_local_osm_and_kdtree.py   (needs DTM 20m TIF)
    → Germany_max_*_long_V0.xml.gz

05_smooth_matsim_network.py
    → Germany_max_*_smoothened_*.xml.gz
```
